# Purpose
To provide the agent with an understanding of Instagram terminology and how it relates to our monitoring app.
# When to use
When discussing features, naming components, or mapping data models to UI elements.
# Relevant Insta Fixer context
Insta Fixer monitors Instagram profiles. It is a utility, not a social network.
# Rules
- Do not invent features like "Messaging" or "Posting". Insta Fixer only reads data.
# Implementation guidance
- Use terminology like "Monitored Profile", "Detected Changes", "Snapshot".
