# Purpose
To guide the visual redesign of Insta Fixer using Instagram-inspired patterns.
# When to use
When writing CSS or HTML for the frontend application.
# Relevant Insta Fixer context
The app is built with vanilla JS and CSS.
# Rules
- Before implementing UI, consult the local research and design-system documents.
- The UI must be: Instagram-inspired, premium, colorful, modern, responsive, accessible, data-driven, monitoring-oriented.
- Do not make it a literal Instagram clone.
# Implementation guidance
- Use the semantic color system. Implement bottom nav on mobile, sidebar on desktop.
