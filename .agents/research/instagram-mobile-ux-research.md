# Instagram Mobile UX Research
## What was researched
Mobile navigation, gesture controls, and touch target sizes.
## Source
Material Design guidelines, Apple HIG, Mobbin UI patterns.
## Date accessed
August 27, 2026
## Relevant observations
- Bottom tab bar with 5 icons.
- Swipe gestures are prevalent (swipe to go back, swipe to DM).
- Modal sheets slide up from the bottom for actions (e.g., sharing, commenting).
## UI pattern
- Edge-to-edge media in Reels.
- Square grids for profile media.
## UX reasoning
- Bottom navigation is easiest to reach with a thumb on large mobile devices.
## How the pattern could apply to Insta Fixer
- Use a bottom navigation bar on mobile for switching between Monitored Profiles, Alerts, and Settings.
## What should NOT be copied
- Gestures that conflict with browser defaults (since Insta Fixer is a web app).
## Implementation implications
- Media queries for max-width: 768px to switch from sidebar (desktop) to bottom tab bar (mobile).
