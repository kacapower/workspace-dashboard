# Instagram Design Patterns
## What was researched
Visual language, typography, and iconography.
## Source
Design systems analysis.
## Date accessed
August 27, 2026
## Relevant observations
- Colors: White/Black backgrounds, #0095f6 for primary buttons, #ed4956 for destructive actions/likes.
- The iconic gradient: used sparingly (story rings, branding).
- Typography: System fonts (-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial).
- Border radius: Soft, typically 8px for cards, 50% for avatars.
## UI pattern
- Minimalist, monochrome UI with color reserved for user content and primary actions.
## UX reasoning
- The UI recedes so the photos/videos pop.
## How the pattern could apply to Insta Fixer
- Use a minimalist, monochrome structural UI. Allow the monitored data/images to provide the color.
- Use a custom gradient ring for active/updated profiles.
## What should NOT be copied
- The exact brand gradient. We should create a unique one for Insta Fixer.
## Implementation implications
- Define CSS variables for spacing, colors, and typography to maintain consistency.
