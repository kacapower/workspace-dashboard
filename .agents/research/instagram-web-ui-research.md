# Instagram Web UI Research
## What was researched
Desktop browser experience.
## Source
instagram.com on desktop.
## Date accessed
August 27, 2026
## Relevant observations
- Left sidebar with primary navigation.
- Center area constrained to ~600-800px width for feed.
- Dialogs for creating posts or viewing followers.
## UI pattern
- Clean, borders and dividers are subtle (e.g., #dbdbdb).
## UX reasoning
- Focuses entirely on the media.
## How the pattern could apply to Insta Fixer
- Desktop dashboard can be wider than the Instagram feed, using the space for data grids or side-by-side comparisons.
## What should NOT be copied
- The extreme constraint on feed width. Data tables need more horizontal space.
## Implementation implications
- Fluid widths for data containers, fixed width for navigation sidebar.
