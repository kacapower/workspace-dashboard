# Instagram Profile UX Research
## What was researched
Profile layout, stats display, grid layout.
## Source
Instagram App (iOS/Android), UI/UX blogs.
## Date accessed
August 27, 2026
## Relevant observations
- Top section: Username in header, Settings/Menu on top right.
- Avatar on left, 3 key metrics on right (Posts, Followers, Following).
- Bio text and link below avatar.
- Action buttons (Follow/Message or Edit Profile/Share Profile) stretch across the width.
- Highlight circles below actions.
- Tabs for Grid, Reels, Tags.
## UI pattern
- Distinct visual hierarchy prioritizing the Avatar and Metrics.
## UX reasoning
- Quick scanability of social proof (followers) and identity (avatar/bio).
## How the pattern could apply to Insta Fixer
- Monitored profiles should have a similar header layout to instantly recognize who is being monitored, but perhaps replace "Posts" with "Changes Detected".
## What should NOT be copied
- The exact terminology if it doesn't fit the monitoring aspect.
## Implementation implications
- Flexbox/Grid layouts will be required to structure the header properly across screen sizes.
