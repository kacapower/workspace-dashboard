# Instagram Navigation Research
## What was researched
Top and bottom navigation, drawer menus.
## Source
Mobile UI references.
## Date accessed
August 27, 2026
## Relevant observations
- Mobile: Bottom tab bar.
- Web/Desktop: Left sidebar for navigation.
## UI pattern
- Icons are outlined when inactive, filled when active.
## UX reasoning
- Clear visual indication of current state.
## How the pattern could apply to Insta Fixer
- Implement a responsive layout: sidebar on desktop, bottom bar on mobile. Active states should use filled icons.
## What should NOT be copied
- The Create button (unless adding a new profile to monitor).
## Implementation implications
- Responsive CSS and potentially different component structures for mobile/desktop headers.
