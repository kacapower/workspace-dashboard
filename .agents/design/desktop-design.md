# Desktop Design Guidelines
## Structure
- Left Sidebar (Fixed, 250px width). Contains logo and main navigation links.
- Top Header (Optional, for search/global actions).
- Main Content Area (Fluid width, max-width: 1200px, centered).
## Layouts
- Dashboard: High-level metrics at the top (Cards), recent activity feed below.
- Profiles: Grid of monitored profiles (Cards) or a detailed list view.
- Analytics: Large charts with wide layout support.
## Interactions
- Hover states on lists and buttons.
- Dialog modals for adding/editing targets.
