# Instagram-Inspired Design System
## Color System (Insta Fixer Semantics)
- Primary Background: #FFFFFF (Light) / #000000 (Dark)
- Surface/Card: #FAFAFA (Light) / #121212 (Dark)
- Border/Divider: #DBDBDB (Light) / #262626 (Dark)
- Text Primary: #262626 (Light) / #F5F5F5 (Dark)
- Text Secondary: #8E8E8E (Light) / #A8A8A8 (Dark)
- **Semantic Colors for Monitoring:**
  - Pink/Purple Gradient: Activity/Changes detected (Story ring equivalent)
  - Blue: #0095F6 (Information/Actions)
  - Green: #4CAF50 (Success/Healthy Polling)
  - Yellow: #FF9800 (Warning/Rate Limits)
  - Red: #ED4956 (Failure/Critical Alerts)

## Typography
- Font Family: system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif
- Page Title: 24px, 600 weight
- Section Title: 16px, 600 weight
- Body: 14px, 400 weight
- Metadata: 12px, 400 weight, secondary color

## Spacing Scale
- 4px, 8px, 12px, 16px, 24px, 32px, 48px, 64px

## Components
- **ProfileAvatar:** Circular, 50% border-radius.
- **StoryRing:** Gradient border around Avatar when changes exist.
- **MediaGrid:** 3 columns, 2px gap.
- **ActivityItem:** Horizontal flex layout with avatar, text, and timestamp.
